# V1.4.6｜量产前10类边界样本清单

**目的**：给模型/确定性评分程序一个可重复执行的短回归集。下面是**设计要求，不是内置训练数据**；测试时应当从真实JD或人工构造的独立样本取得对应OCR原文，预先冻结人工标签。

| 类别 | 期望验证的行为 |
|---|---|
| 1. 没有岗位名称 | `job_title=未提及`，不能虚构字段证据 |
| 2. 应届/经验不限 | 不能因为出现“成长快”推成5年资历 |
| 3. 页面经验不限，正文要求5年以上 | 正文明确必需年限优先并留冲突证据 |
| 4. C++为任选语言之一 | 不得当成C++必需红线 |
| 5. Java/Spring后端为核心职责 | 仅符合当前画像红线时1分，其他画像正常评估 |
| 6. 外包/驻场明确 | 对排除外包的画像必须触发1分 |
| 7. 模型预训练和底层算法主岗 | 区分研究研发与Agent应用协作 |
| 8. 纯BI/取数数据分析，却写AI标题 | 用真实主要职责判方向，不因AI关键词给高分 |
| 9. 同一句话同时提技能和学历 | evidence_quotes应去重，所有引文必须为原文字串 |
| 10. 超长JD + 中文路径 + 网址 | OCR原文保真，CSV/XLSX不乱码，Excel超长单元格明确标识并保留原始来源 |

量产前流程：先跑这10类验证Schema/证据约束；再用150–300条分层样本校准岗位分布；**两者都通过并冻结画像/规则版本后**才运行上万条批次。任何评分规则修改都应保留前一版运行供回归比较。没有可靠标注或基线不应对外宣称“准确率提高”。
