# 运行前用户引导（V1.4）

运行 `python scripts/run.py welcome` 取得完整 Markdown 并原样展示，作为首屏介绍与三个参考画像。

**不可仅输出“正在初始化”或把介绍写在日志里。** 之后逐项核对：目标方向、经验、已有技能、城市薪资、硬性排除、职责偏好、抗压偏好。已见于用户输入的值必须标注 **已识别**，待补充信息再简短询问。支持 A/B/C 单选或自定义文字；目标行业与可接受岗位可多选。抗压强/一般/弱必须单选，除用户主动跳过时保留 unspecified。

A/B/C 为示例测试画像，不代表用户真实经历；不得将示例用户的红线、技能移植到其他画像。支持用户一次直接粘贴所有文字。只有在明确确认已掌握技能清单完整时才设 `skills_confirmation_complete: true`。

Agent提取用户本轮已粘贴的画像文字到临时JSON后，执行 `python scripts/run.py profile-preview --file 草稿.json`，将“已识别：...”和“待补充”列表呈现在聊天中。
